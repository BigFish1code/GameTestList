# GameTestList<br>
本项目为个人游戏《命运牌契》的完整测试文档，展示我对游戏功能测试的理解与实践能力。<br>
测试类型：黑盒测试为主<br>
测试方法<br>
 **等价类划分**：对能量值（0/1/≥cost）、HP（0/满血/中间值）分类选取代表值<br>
 **边界值分析**：重点测试伤害致死边界、能量不足临界、HP回满上限<br>
 **判定表**：针对“力量Buff × 敌人护甲”组合，覆盖全部4种条件（详见ATK-01~04）<br>
 **场景法**：端到端梳理从启动→选关→战斗→Boss→通关的主流程<br>
 **状态机验证**：地图房间 Locked→Attainable→Visited 完整流转<br>

  - 卡牌战斗逻辑 / 地图系统 / UI与状态流转 / 攻击模块判定表 / 场景流 / BUG报告
