# GameTestList
Test for my game
测试方法
  **黑盒测试**：基于功能需求设计用例，不依赖代码实现
  **等价类划分**：对输入条件分类，选取代表值测试
  **边界值分析**：重点测试临界值（如能量=0、HP刚好致死）
  **判定表**：多条件组合场景（如Buff+护甲同时存在）
  **场景法**：模拟玩家实际操作流程
用例设计思路
  **卡牌战斗逻辑**：从能量消耗、伤害公式（value×力量系数−防御）、Buff/Debuff持续回合三个维度设计用例，覆盖单条件正向/逆向、边界致死/过杀、多条件组合。
  **肉鸽地图系统**：围绕房间状态机（Locked→Attainable→Visited）设计状态流转用例，验证随机生成合理性与商店交互完整性。
  **UI与状态流转**：验证数据变化到UI更新的实时性、按钮防连点、界面跳转正确性。
