《命运牌契》 Roguelike卡牌游戏 - 功能测试用例集

【作品简介】
本作品为针对一款单机Roguelike卡牌游戏独立设计的完整功能测试方案。
游戏特点：单局制、本地存档、退出清空、随机地图生成。

【测试范围】
• 卡牌战斗逻辑（能量/伤害/Buff/治疗/防御）
• 地图系统（关卡解锁/状态迁移/随机生成）
• UI状态流转（实时数值更新/回合切换/弹窗交互）
• 攻击模块判定表（力量Buff × 护甲 组合覆盖）
• 端到端场景流（从启动到通关的完整玩家旅程）

【测试方法运用】
等价类划分 | 边界值分析 | 判定表 | 状态迁移图 | 场景流

1. 针对"无存档"特性，专项设计防软锁用例（UI-09/UI-10）
   → 模拟玩家疯狂连点、点击弹窗空白处等极端操作，确保界面不卡死
2. 使用判定表法覆盖"力量Buff × 护甲"的2×2组合场景（ATK-01~04）
3. 缺陷报告中包含致命级Bug × 1、严重级 × 2，附完整重现步骤

【文件导航】
